# 🌸 Tipos de Flores 🌸

> ✿ A tiny, cute HTML page full of flowers ✿ (◕‿◕)♡

Hiii~ welcome to my little flower garden! 🌷
This is a school project I made in my HTML class to practice **tables** and **links**.
It shows 9 different types of flowers, each with its name and a picture, all organized in a table. 💐

## 🌼 What's inside?

| 🌹 Rosa | 🌺 Clavel | 🌸 Petunia |
|:---:|:---:|:---:|
| 💜 **Jacinto** | 🌿 **Gerardo** | 🌼 **Margarita** |
| 💐 **Gladiolo** | 🦋 **Orquídea** | 🌷 **Tulipán** |

---

## 🎀 What I practiced

- 🧸 **Tables** → `<table>`, `<tr>` and `<td>` to build the flower grid
- 🔗 **Links** → `<a href="">` to connect pages
- 🖼️ **Images** → `<img>` with `src` and `width`
- 🎨 **Background color** → a soft pink page, because pink is cute ♡
